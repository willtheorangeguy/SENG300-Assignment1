## Build

1. Install **Java 21 (JDK)**. Check your installation with `java -version`.
2. Open a terminal in the project folder containing `pom.xml`.
3. Run the command for your operating system:

**Windows (PowerShell):**

```powershell
./mvnw.cmd clean package
```

**macOS / Linux:**

```sh
./mvnw clean package
```
